# Detection of copy number variation using WGS
Workflow for running CNV analysis using read depth methods (CNVnator and CNVcaller). Here is a paper I published using this workflow (https://doi.org/10.1371/journal.pone.0353468). 
You can also find scripts on running LUMPY a split read based method for detecting CNVs. 

Full workflow steps found here (https://tafarakundai.github.io/WGS_copy_number_variation/)
