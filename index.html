Whole Genome Sequencing Copy Number Variation Pipeline

A workflow for identification and annotation of CNVs using read-depth and structural variation approaches

About the Pipeline

This repository contains scripts, documentation, training materials, and example resources for whole genome sequencing (WGS) copy number variation (CNV) analysis.

The workflow integrates CNV detection methods including:

  • CNVnator
  • CNVcaller
  • LUMPY Express
  • CNV merging and annotation
