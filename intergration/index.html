CNV Intergration

Overview

Once you have results from two or three software the most important part is to intergrate the results. In this workflow you will learn how to merge output from two software (CNVcaller and CNVnator). If you need scripts for merging three software check out this script "merge_all_three".

Overview

This step identifies copy number variations from whole genome sequencing data using CNV calling algorithms.

Tools Used

  • CNVnator
  • CNVcaller
  • LUMPY Express
